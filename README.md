## 📌 Visão Geral

O **Encrypting** é uma aplicação web responsiva projetada para fornecer serviços gratuitos de criptografia e descriptografia de textos. O objetivo do projeto foi criar uma ferramenta com interface intuitiva e visual minimalista para fins acadêmicos e educacionais, permitindo que os usuários compreendam na prática o funcionamento de cifras clássicas e codificações.

O sistema opera integralmente no lado do cliente (Client-Side), sem a necessidade de um banco de dados, garantindo que as informações digitadas pelos usuários não sejam armazenadas e assegurando a privacidade durante a utilização.

---

## ⚙️ Funcionalidades

O site permite criptografar e descriptografar mensagens em tempo real utilizando três métodos distintos:

* **Cifra de César:** Deslocamento de caracteres baseado em uma chave numérica (key) definida pelo usuário.
* **Código Binário:** Conversão de strings de texto para sequências de bits (0s e 1s) usando o valor numérico dos caracteres (`charCodeAt`).
* **Código Morse:** Tradução de caracteres alfanuméricos para o padrão de pontos e traços.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias fundamentais da web, sem o uso de frameworks, demonstrando domínio na manipulação da árvore DOM e lógica de programação:

* **HTML5:** Estruturação semântica das páginas e formulários de entrada.
* **CSS3:** Estilização responsiva, layout flexível e design minimalista focado na usabilidade.
* **JavaScript (Vanilla JS):** Lógica de conversão das cifras, manipulação de strings, arrays, loops e eventos do DOM.
* **Vercel:** Hospedagem e deploy contínuo da aplicação.
